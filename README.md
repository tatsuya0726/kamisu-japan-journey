# 神栖を守れ！！

神栖の町を猫チームで守る、ブラウザ向けタワーディフェンス試作です。

[ゲームを開く](https://tatsuya0726.github.io/kamisu-japan-journey/) · [現在の実装・検証・制約](docs/PLAYABLE-CANDIDATE.md) · [旧引き継ぎ資料](docs/CLAUDE_HANDOFF.md)

**キキとネネ、農家猫・配達猫、4種類の派生猫で遊べます。** 丸い地点を選ぶ作戦マップ、実座標の7地点のまち歩き、施設の外観を参考にした創作背景・猫イベントを追加しました。戦場は左右に見渡せ、カード欄だけを横スクロールできます。本格的なコマアニメーションは未導入です。[今回の仕様・素材・検証](docs/MAP-AND-COMPANIONS.md)

## あそび方

港・波崎海岸・大野原から作戦を選びます。時間で増えるごはんを使い、基本・盾・遠距離・俊足の猫を出撃させます。猫は自動で進み、架空の侵略者を追い返します。敵アジトのHPを0にすれば勝利です。

カードをクリック／タップ、または1〜8キーで出撃。A・Dで戦場を左右へ、Homeで町へ、Endで敵へ。カードは横ドラッグ、Qで右へ送れます。Pで停止。倍速と「おまかせ」補助も使えます。勝敗後は再戦でき、勝利後は次の作戦へ進めます。クリア記録のみ端末ごとに保存し、旧・日本旅のセーブは変更しません。
