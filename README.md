# 神栖を守れ！！

神栖の町を猫チームで守る、ブラウザ向けタワーディフェンス試作です。

[ゲームを開く](https://tatsuya0726.github.io/kamisu-japan-journey/) · [現在の実装・検証・制約](docs/PLAYABLE-CANDIDATE.md) · [旧引き継ぎ資料](docs/CLAUDE_HANDOFF.md)

**主役のクリーム猫・銀色猫と、農家猫・配達猫で遊べます。** 承認済みの敵4種、神栖マップ、背景3種、両拠点を組み込みました。仲間16体のうち今回は2体を採用。残り14体と本格的なコマアニメーションは未導入です。[素材の出典・導入範囲](docs/DRIVE-ASSET-INTEGRATION.md)

## あそび方

港・波崎海岸・大野原から作戦を選びます。時間で増えるごはんを使い、基本・盾・遠距離・俊足の猫を出撃させます。猫は自動で進み、架空の侵略者を追い返します。敵アジトのHPを0にすれば勝利です。

カードをクリック／タップ、または1〜4キーで出撃。Pで停止。倍速と「おまかせ」補助も使えます。勝敗後は再戦でき、勝利後は次の作戦へ進めます。クリア記録のみ端末ごとに保存し、旧・日本旅のセーブは変更しません。
