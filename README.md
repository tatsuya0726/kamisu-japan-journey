# こもれび日本旅 — 神栖・港からの旅

茨城県・神栖（かみす）。海と川のあるまちから始まる、小さな2D冒険ゲーム。Phaser / TypeScript / Vite。

## 遊び方

目的地をクリック・タップ、矢印/WASD、スマートフォン幅の方向ボタンで移動。昼は収集と住民の依頼、夜は売買・料理・拠点づくり。クイズではなく、品物の使い道と陣地の取り方を考えます。

- 出発地は創作の「神栖・しおかぜ港」。左のピーマン畑で箱づめを手伝い、こはるへ2つ届けると8コイン。
- 木材3つ＋8コインで小屋へ。翌朝の元気が6から8に増えます。
- れんこん1つ＋栗1つでお弁当。旗取りで1試合1回、行動＋1。
- 旗取りは5×5、各2行動・8ラウンド。色のマス1点、中央旗は追加3点。同じマスに入ると相手を押し戻します。
- 勝利6コイン、その他2コイン。再戦できます。
- ブラウザ内に自動保存。別端末や別URLへは自動同期しません。リセット直前の記録は設定から戻せます。

## 開発

Node.js 24。`npm ci`、`npm test`、`npm run build`、`npm run preview`。

`src/data/world.ts` は地域・特産品・依頼、`src/systems/` はルールと保存、`src/scenes/` は描画、`src/ui/` はUI。配布物は `dist/`。GitHub Pagesは同じリポジトリのmainへのpushで更新。相対baseと相対素材URLを使用。

## 事実と創作

神栖の県内位置、東の鹿島灘、西の利根川、ピーマン栽培は市公式資料を参照。港町・人物・道・依頼・経済・料理効果は創作です。「しおかぜ港」は実在の鹿島港や波崎漁港の再現ではありません。探索は茨城の旅先を縮めた模式図で、実際の距離・形・隣接を示しません。
